main > section#html

HTML diz o que cada parte é.

Antes de qualquer cor ou animação, a página precisa de estrutura. Role dentro desta seção e veja o documento ser montado tag por tag, enquanto o navegador desenha o resultado.

  1. Cabeçalho e navegação

    header e nav dizem ao navegador e aos leitores de tela onde estão os links principais.

  2. Conteúdo principal

    main marca o que é único na página, e só existe um. O h1 dá o assunto.

  3. Imagem e ação

    alt descreve a imagem para quem não a vê. button recebe foco e responde ao teclado sem trabalho extra.

  4. Rodapé

    footer fecha a página com autoria e contato, e vira um ponto de referência na navegação.

Flexbox

Alinha itens em uma linha e reparte o espaço que sobra.

justify-content: flex-start;

.grade { display: grid }

Grid

Define linhas e colunas e deixa o navegador encaixar cada item.

12345678

:root { --h: 210 }

Variáveis

Um valor, declarado uma vez, controla vários componentes ao mesmo tempo.

--h: 210;
--r: 8px;

.bola { transition: transform }

Transições

A curva de tempo muda a sensação do movimento. Anime só transform e opacity.

transition: transform 900ms ease;

Container queries

O componente reage ao espaço que ele mesmo tem, não ao tamanho da tela.

JavaScript responde ao que a pessoa faz.

Um clique não acontece só no botão. Ele desce da janela até o alvo (captura) e sobe de volta (bolha). Clique no botão C e acompanhe o caminho.

Delegação de eventos: um único ouvinte na lista atende todos os itens, inclusive os que ainda nem existem.

lista.addEventListener('click', (e) => {
  const item = e.target.closest('button');
  if (item) item.classList.toggle('done');
});
